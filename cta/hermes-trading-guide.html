02Add TradingView MCP to Hermes

The TradingView MCP gives Hermes direct access to technical indicators and OHLCV candle data across all major exchanges. No TradingView account needed — it reads public market data.

Install command:

uvx --from mcp-tradingview-server mcp-tradingview

Add to Hermes mcp.json:

{
  "mcpServers": {
    "tradingview": {
      "command": "uvx",
      "args": ["--from", "mcp-tradingview-server", "mcp-tradingview"]
    }
  }
}

Tools this unlocks in Hermes: get_indicators, get_historical_data, get_specific_indicators — covering RSI, EMA, Bollinger Bands, MACD, and full OHLCV candles.

03Add Hyperliquid MCP to Hermes

The Hyperliquid MCP lets Hermes place orders, manage positions, and read account state directly on Hyperliquid perpetuals. It wraps the official Hyperliquid SDK.

Install command:

npx -y hyperliquid-mcp

Full mcp.json with both servers:

{
  "mcpServers": {
    "tradingview": {
      "command": "uvx",
      "args": ["--from", "mcp-tradingview-server", "mcp-tradingview"]
    },
    "hyperliquid": {
      "command": "npx",
      "args": ["-y", "hyperliquid-mcp"],
      "env": {
        "HL_PRIVATE_KEY": "your_api_wallet_private_key",
        "HL_WALLET_ADDRESS": "your_main_wallet_address"
      }
    }
  }
}

Get your Hyperliquid API key:

  1. 1.Go to app.hyperliquid.xyz/API
  2. 2.Click Generate API Wallet → name it "hermes-trader"
  3. 3.Paste your main wallet address → Generate
  4. 4.Click Authorize API Wallet
  5. 5.Copy the Private Key — you only see it once
Security: The API sub-wallet can trade but cannot withdraw. Only fund it with what you can afford to lose.

1. Use TradingView MCP to get ETH-USDT indicators on Binance, 1H timeframe

Risk rules:
- Max open exposure: $500
- 3 consecutive losses → pause, notify me
- No trading 00:00–04:00 UTC
