01 Deploy Hermes on myhermes.cloud

myhermes.cloud is the one-click host for Hermes Agent. No terminal, no Docker, no VPS. Your agent runs 24/7 on a managed server and stays alive even when your phone is off. This is what makes the whole system possible — Hermes is the brain that never sleeps.

  1. 1.Go to myhermes.cloud and click Deploy Agent
  2. 2.Choose your model — Kimi K2.6 via OpenRouter recommended ($0.95/M tokens)
  3. 3.Your agent gets a URL: https://your-agent.myhermes.cloud
  4. 4.Save this URL — it becomes your TradingView webhook endpoint
Why myhermes.cloud? A local agent goes offline when your laptop does. myhermes.cloud keeps Hermes running continuously so it never misses an alert.
02 Get Your Hyperliquid API Key

Hyperliquid uses wallet-based API keys. You generate a sub-wallet that can trade on behalf of your main account but cannot withdraw funds.

  1. 1.Go to app.hyperliquid.xyz/API
  2. 2.Click Generate API Wallet — name it "hermes-trader"
  3. 3.Paste your main wallet address → click Generate
  4. 4.Click Authorize API Wallet
  5. 5.Copy the Private Key — you only see it once
Security: This sub-wallet can trade but cannot withdraw. Only fund it with what you are prepared to risk.

Paste this into Hermes to store your keys:

Store the following securely in my memory:
- Hyperliquid API wallet address: [your API wallet address]
- Hyperliquid private key: [your private key]
- Main wallet address: [your main wallet]
- Trading pair: ETH-PERP
- Max position size per trade: $100

Never expose these in logs or outputs.
03 Set Up TradingView Webhook Alert

TradingView sends a JSON payload to your Hermes URL every time your alert condition triggers. This is how the signal travels from chart to trade.

  1. 1.Open TradingView and go to your chart
  2. 2.Set up your strategy or indicator
  3. 3.Click Alerts (bell icon) → Create Alert
  4. 4.Set your condition
  5. 5.Under Notifications → enable Webhook URL
  6. 6.Paste your Hermes URL: https://your-agent.myhermes.cloud/webhook
  7. 7.In the Message box, paste this JSON:

Alert message payload:

{
  "action": "{{strategy.order.action}}",
  "ticker": "{{ticker}}",
  "price": "{{close}}",
  "time": "{{time}}",
  "interval": "{{interval}}",
  "size": "0.01"
}

Replace 0.01 with your position size in ETH.

04 Tell Hermes What To Do With Signals

Hermes needs a strategy prompt — the rules it follows every time a signal comes in. Paste this into your Hermes agent:

You are my automated trading agent for Hyperliquid perpetuals.

When you receive a webhook from TradingView:
- action "buy" → open LONG on the ticker
- action "sell" → open SHORT or close existing LONG
- Use the size value from the payload
- Use Hyperliquid credentials stored in memory
- Log every trade: entry price, side, size, timestamp

Risk rules:
- Never exceed $500 total open exposure
- If 3 consecutive trades are losses, pause and
  notify me via Telegram
- Do not trade on weekends (UTC)

After each trade, send Telegram message:
Trade: [LONG/SHORT] [ticker] @ $[price]
Size: [size] | Time: [time]
The Telegram notification is built into Hermes — no extra config needed if you connected Telegram during setup on myhermes.cloud.
05 Test Before Going Live

Do not skip this. Fire a test alert before trusting real money to the system.

  1. 1.TradingView → your alert → three dots → Test alert
  2. 2.Check Hermes dashboard — webhook should show as received
  3. 3.Check Telegram — Hermes should send a trade confirmation
  4. 4.Check Hyperliquid → Positions — test order should appear
  5. 5.Close the test position manually, then set the strategy live
